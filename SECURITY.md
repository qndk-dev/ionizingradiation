# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.21.11   | ✅        |

These versions apply to Minecraft.

## Reporting a Vulnerability

Please **do not** open a public issue.

Report via [GitHub Private Security Advisory](https://github.com/qndk-dev/lonizingradiation/security/advisories/new)
or email: occupiednine@proton.me

We'll respond within a week. If the issue is confirmed, we'll aim to patch it
before any public disclosure.

## Scope

**In scope:**
- Server-side exploits (malicious packets, command injection, etc.)
- File system vulnerabilities (path traversal in config handling)
- Any exploit allowing arbitrary code execution

**Out of scope:**
- Gameplay bugs and duplication glitches (open a regular issue)
- Crashes without security impact
- Issues requiring physical server access

## Сообщая об уязвимости

Пожалуйста, **не открывайте** публичные Issue.

Сообщите нам в [GitHub Private Security Advisory](https://github.com/qndk-dev/lonizingradiation/security/advisories/new)
или через электронную почту: occupiednine@proton.me

Мы ответим в течение недели. Если проблема подтверждена, мы будем исправлять её
до любого публичного раскрытия уязвимости.

## Область действия

**Входит:**
- Серверные эксплойты (вредоносные пакеты, инъекция команд и т.д.)
- Уязвимости в файловой системе (обход путей при обработке конфигурации)
- Любой эксплойт, способный выполнять произвольный код

**Не входит:**
- Баги дюпа и геймплейные баги (откройте обычный Issue)
- Любые сбои, которые не влияют на безопасность
- Проблемы, требующие доступа к физическому серверу
